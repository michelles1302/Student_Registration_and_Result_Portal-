# Student Registration & Result Portal

## Overview

The Student Registration & Result Portal is a responsive frontend web application that allows students to enter their personal and academic details, enter subject marks, and view their calculated examination results.

The project demonstrates the integration of HTML5, Bootstrap 5, CSS3, and JavaScript to create an interactive and responsive web application.

## Features

- Student personal details registration
- Course selection
- Subject-wise mark entry
- Automatic calculation of total marks
- Automatic percentage calculation
- Pass/Fail status determination
- HTML5 form validation
- Dynamic display of student details and results
- Responsive layout for different screen sizes
- Bootstrap cards, forms, tables, buttons, and responsive grid
- Print result functionality
- Reset and edit options
